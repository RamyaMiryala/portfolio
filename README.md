# Ramya Miryala - personal portfolio

Static site (HTML + CSS + JS). No build step.

## Publish on GitHub Pages
1. Create a repo named `ramyamiryalaofficial.github.io` (user site) on github.com/ramyamiryalaofficial.
2. Upload all files from this folder to the repo root (index.html must be at the root).
3. Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
4. Site goes live at https://ramyamiryalaofficial.github.io in 1-2 minutes.

## Edit
- Text and links: `index.html`
- Colours and fonts: `css/style.css` (variables at the top)
- Photo: replace `images/ramya.jpg`
- Telugu intro line in the About section is a placeholder - replace it or delete that `<p lang="te">`.
